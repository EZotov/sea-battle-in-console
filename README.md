# ⚓ Sea Battle in Console (Морской бой)

Классическая игра «Морской бой» для терминала, написанная на TypeScript с использованием чистого Node.js (ES-модули, без сторонних рантайм-зависимостей).

## ✨ Особенности

* **Настраиваемый размер поля:** поддержка квадратных полей от `6×6` до `19×19` с автоматическим подбором состава флота.
* **Enemy Bot (Hunt & Target):** ИИ стреляет по шахматной сетке в режиме поиска, определяет ось корабля при повторном попадании и автоматически исключает ореол вокруг потопленных судов.
* **Чистая архитектура:** разделение на модели данных (`Board`, `Ship`), логику противника (`Bot`), игровой движок (`GameEngine`) и консольный интерфейс (`Renderer`).
* **Нулевые внешние зависимости:** работа с терминалом реализована через встроенный модуль `node:readline/promises`.
* **Рандомная расстановка кораблей:** временно сделана рандомная установка кораблей.

## 🚀 Установка и запуск

1. **Клонируйте репозиторий и установите зависимости:**
   ```bash
   yarn install
   ```

2. **Запуск в режиме разработки:**
   ```bash
   yarn dev
   ```

3. **Сборка и запуск продакшен-версии:**
   ```bash
   yarn build
   yarn start:prod
   ```

## 🎮 Как играть

1. При запуске введите желаемый размер игрового поля (число от **6** до **19**).
2. Корабли игрока и противника расставляются автоматически.
3. Вводите координаты выстрела в формате **`БукваЦифра`** (например: `А1`, `Д10`, `К5`).
4. При попадании ход остаётся за вами. Вокруг потопленного корабля автоматически проставляются промахи.
5. Для досрочного выхода введите `exit` или нажмите `Ctrl + C`.
